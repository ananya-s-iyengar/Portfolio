About Me

Professional background, focus areas, and technical interests

I am a Cybersecurity Analyst supporting enterprise AWS cloud security operations in an IBM client environment. My work focuses on Tier-1 SOC alert triage, cloud security incident investigation, threat analysis, and remediation coordination.

I work with AWS security services including GuardDuty, Security Hub, CloudTrail, and IAM, and investigate findings involving services such as S3, RDS, SES, and Kubernetes workloads. I also use ServiceNow to support incident and remediation workflows.

Alongside my professional work, I build cybersecurity monitoring, log analysis, threat detection, AI, and security tooling projects using Python and related technologies.
